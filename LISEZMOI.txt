MISE A JOUR APHRODITE (etapes 5 + 6 + commandes)

1. Dezippe ce dossier A LA RACINE du projet (la ou se trouve manage.py).
   Accepte de REMPLACER les fichiers existants.
2. Cree le dossier vide s'il n'existe pas : templates/orders
   (il est deja dans le zip).
3. Modifie config/settings.py :
   - INSTALLED_APPS : ajouter  'apps.orders',  (et verifier 'apps.moderation', 'apps.creators')
   - MIDDLEWARE : ajouter apres MessageMiddleware :
         'apps.moderation.middleware.ModerationMiddleware',
   - TEMPLATES > OPTIONS > context_processors : ajouter :
         'apps.orders.context.commandes_a_traiter',
4. config/urls.py : ajouter dans urlpatterns :
       path('', include('apps.orders.urls')),
5. Terminal :
       python manage.py makemigrations accounts economy shop moderation orders
       python manage.py migrate
       python manage.py runserver
6. Ctrl+F5 dans le navigateur.
